# Hybrid Probability Estimation via Log-Odds Offset Stacking

This repository contains the code and figures supporting the paper:

Hedson Malata  
"Hybrid probability estimation via log-odds offset stacking with hierarchical calibration"

## Contents

paper/
    LaTeX manuscript and bibliography

code/
    Python scripts used to generate evaluation figures

figures/
    ROC, calibration, and precision–recall plots

## Requirements

Python 3.x  
numpy  
pandas  
matplotlib  
scikit-learn

## Reproducing the figures

Run:

generate_main_figures.py
